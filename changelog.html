Changelog

Newest first · Feature releases are numbered; individual dates are not tracked

v6 — Bestiary, Export & Print, Settings current release · additive module, no changes to existing tools
  • 📚 Bestiary — searchable collection of 80+ SRD creatures with stat summaries; send any creature's HD straight to the Calculator or load its full stats.
  • 🖨️ Export & Print — Foundry VTT JSON, Roll20 JSON and Roll20-friendly paste text for statblocks, plus a clean printable sheet via the browser's print dialog.
  • ⚙️ Settings — HP rounding mode (round vs. floor, stored in ddhp_rounding), full backup/restore of app state as JSON, and an auto-save status indicator.
  • 🖥️ Deployment packaging — static hosting files added: security headers (_headers), SPA fallback (_redirects), Wrangler config, GitHub Actions deploy workflow, README, license and editor config; strict Content-Security-Policy enforced site-wide.
v5 — Power tools (Tier 1 + Tier 2) nine self-contained modules with their own storage
  • 🎰 Dice Sandbox — keep highest/lowest, exploding dice, reroll thresholds.
  • 🗡️ Damage vs Target — apply damage through temp HP and resistance, with the resulting concentration DC.
  • 📊 Ability Scores — 4d6 drop lowest, 3d6, standard array and a point-buy reference table.
  • ✨ Spell DC — save DC and spell attack bonus with hit/save probability readouts.
  • 📖 Conditions — searchable conditions reference, including both 2014 and 2024 exhaustion ladders.
  • ⚖️ CR Estimator — quick defensive/offensive CR averaging from HP, AC, DPR and attack bonus.
  • 🏕️ Rest & Recovery — short-rest hit-dice spending and long-rest rules for both rulesets.
  • 🎯 d20 Odds — success probability with advantage, disadvantage and elven accuracy.
  • 🧑 NPC Generator — name, race, role and trait/ideal/bond/flaw/hook rolls for quick table NPCs.
v4 — DM extras first add-on module; purely additive
  • 💰 Loot Roller — DMG-style treasure hoard rolling by CR tier.
  • 🎲 Random Encounter — environment-based encounter generation with twist tables.
  • 🐲 Lair & Legendary — legendary and lair action block builder with Markdown export.
  • ☠️ Kill Probability — exact hit/crit/mitigation math with cumulative kill odds per round.
v1 → v3 — The core twenty the original single-page toolkit
  • The twenty core tabs shipped and stabilised: 🧮 Calculator, 🐉 Creature Builder, 🛡️ Effective HP, 🔍 Reverse Engineer, 🧝 PC Builder, 📊 Probability, 📜 Statblock, ⚖️ Compare, 🧬 Templates, 🏰 Encounter, ⚔️ Combat, 🎲 Monster Tools, 💀 PC Tools, 🎯 CR Calc, 🎯 Concentration, 📅 Day Budget, 📊 Party Radar, ⚡ Combat Tracker, 🎲 Monte Carlo and 📈 XP Tracker.
  • Strict dice-expression parser with loud error messages, caps (1,000 dice, d1,000 faces) and exact-vs-simulated distribution switch at 200 dice.
  • Auto-save (1.5 s debounce), 20 named save slots, corrupted-storage recovery, shareable #s= links, keyboard shortcuts, dark mode and a generated web-app manifest (no service worker).
  • Accessibility pass: WAI-ARIA tab pattern, arrow-key tab navigation, aria-live result regions, escaped HTML everywhere user input is rendered.
  • Light/dark theming via CSS custom properties, mobile-first responsive layout, and a print stylesheet that strips the chrome.

Upgrade notes: every add-on module was built to be purely additive — v4, v5 and v6 never modified the original twenty tools or their saved data. Restoring an old backup into the current version is safe; new keys (ddhp_rounding, ddhp_xpHistory) are created only when you use the features they belong to.
